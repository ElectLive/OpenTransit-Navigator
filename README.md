# OpenTransit-Navigator

> 🚧 **项目状态与 AI 声明**
> 本项目目前处于 Phase 1 初始验证阶段。仓库内现有的架构、文档及设计草案均由 AI 辅助生成，用于快速呈现产品形态与需求边界。我们正在招募技术负责人，以进行实质性的代码开发与架构重构。

一个可自行部署、支持多模式联程与海量方案返回的开源公共交通导航引擎。

## 项目简介

现有的公共交通导航工具在产品设计上通常追求单一最优解，存在方案数量展示上限（如最多10条），并在底层自动过滤掉部分绕路、多次换乘的方案；同时，公共自行车等微出行方式往往缺乏深度的路由整合。

本项目旨在基于开源路由引擎（OpenTripPlanner），构建一个参数可调的出行规划系统。我们希望通过自定义数据管道与算法配置，实现对海量备选方案的完整展示，将更多路线的选择权交还给用户。

## 当前阶段路线图 (Phase 1 Roadmap)

- 边界限定：首期 Demo 严格锁定杭州市区（公交 + 地铁），暂不包含跨城火车与公共自行车。
- 技术验证目标：跑通 CPTOND-2025 数据转换 -> OTP 本地 Docker 部署 -> 开启调试模式返回至少 10 条方案，并保留多换乘路线。
- 详细执行清单请见 [docs/roadmap.md](https://github.com/ergjk/OpenTransit-Navigator/blob/main/docs/roadmap.md)。
